# Blanket
*Adventuring gear*  


- **Cost**: 5 sp
- **Weight**: 3.0 lbs.

While wrapped in a blanket, you have [[Rules/Source/variant-rules/advantage-xphb\|Advantage]] on saving throws against [[Rules/Source/traps-hazards/extreme-cold-xdmg\|extreme cold]] (see the "Dungeon Master's Guide").

*Source: Player's Handbook (2024) p. 224. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)*
