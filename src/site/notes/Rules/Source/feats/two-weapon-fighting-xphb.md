# Two-Weapon Fighting
*Source: Player's Handbook (2024) p. 210. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)*  

**Prerequisite**: Fighting Style Feature

When you make an extra attack as a result of using a weapon that has the [[Rules/Source/item-properties#Light\|Light]] property, you can add your ability modifier to the damage of that attack if you aren't already adding it to the damage.
